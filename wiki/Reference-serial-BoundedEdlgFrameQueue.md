# serial/BoundedEdlgFrameQueue.hpp — optional EDLG FIFO

**Public optional EDP-Serial adapter** on `feature/logging-v1`, version `0.1.0`. Does not enter the default Serial umbrella. Application imports `EDP-Serial`, **EDP-Logging** canonical EDLG framing and the **EDP-Threading** ordinary Mutex capability; all are abstractions, Bootstrap selects concrete platform Mutex and ByteStreamWriter providers. No deprecated `ESPressio-*` library.

- `EdlgQueueOfferStatus`: `Queued / Full / LockUnavailable / MutexProviderFailure / InvalidCodec / InvalidPayload / QueuedButLockReleaseFailed / Poisoned`.
- `EdlgQueueOfferResult`: `Status`, truthful `FrameWasQueued`, `DepthAfterAttempt`. An insertion followed by failed lock release retains the frame and poisons, NEVER lies that it was unqueued.
- `EdlgQueuePumpStatus`: `Empty / Complete / WouldBlock / ProviderFailure / EndpointContractViolation / LockUnavailable / MutexProviderFailure / LockReleaseFailed / Poisoned`.
- `EdlgQueuePumpResult`: `Status`, `FrameCompleted` (can be true even if lock release failed afterward), accepted prefix/total frame bytes and queue depth.
- `BoundedEdlgFrameQueue<FrameCapacity,MaxPayloadBytes,TMutexProvider>`: fixed array of owner-qualified `EdlgFramePump` elements; borrow a Bootstrap-composed EDP-Threading OrdinaryMutex provider whose `Identity`, CompositionOffers and typed noexcept TryAcquire/Release contract are compile-time enforced. `TryEnqueue(codec,payload)` reserves one FIFO slot by **single NoWait mutex acquisition**, formats/copies a whole frame, advances tail only on success and rejects Full/Busy. `PumpNext(endpoint)` holds same Mutex while pumping the oldest frame's **only unaccepted suffix** and removes it ONLY when all bytes were accepted. Nonblocking partial-native output cannot interleave with the next frame from this queue.
- `Depth() const noexcept` and `Poisoned() const noexcept`: lock-free atomic snapshots.

**Critical limits:** Exclusive endpoint ownership is a required Bootstrap contract. This queue only coordinates writers that participate in **this one queue**; another direct UART writer or independent queue can corrupt the stream. FIFO admission does not guarantee fairness to rejected producers. Never destroy with pending records; no stop/seal/worker/persistence/loss-provenance handling yet. An endpoint accepting bytes is NOT evidence of hardware flush, delivery or durability. A failed Mutex Release permanently poisons the queue; no unsafe Reset exists. Real Arduino/ESP-IDF ByteStreamWriter providers, complete physical target builds and HIL are outstanding.

**Tests:** `tests/BoundedEdlgFrameQueueTests.cpp` and `tests/run-bounded-edlg-queue-tests.sh`. Real composition offers with mock host providers, 8 competing producers × 12 repeats, partial output, verified complete CRC EDLG frames, full FIFO, native TryAcquire/Release failure, sticky poison. ## Source-complete private FIFO state and native failure transition — 12 November 2026

**Source:** [src/serial/BoundedEdlgFrameQueue.hpp](../src/serial/BoundedEdlgFrameQueue.hpp). Template `TFrameCapacity` is a positive compile-time number of stable slots; `TMaximumPayloadBytes` fixes each EDLG payload ceiling; `TMutexProvider` must be a real application-chosen EDP-Threading ordinary keyed Mutex Composition with exact noexcept typed TryAcquire/Release. The implementation requires always-lock-free atomic size_t/bool on the selected target. No runtime allocator, hidden Clock or native UART concrete is instantiated.

**PRIVATE `_mutex`** is a borrowed stable provider pointer owned by Bootstrap; **`_frames`** is the fixed array of complete locally-owned `EdlgFramePump` frames; **`_head`** selects the oldest frame; **`_tail`** the next candidate insertion; **`_depth`** is atomic published occupancy; **`_poisoned`** is the sticky terminal indicator if a native Mutex release cannot be verified. Private `Next(index)` wraps at the compile-time number of slots, and private `ReleaseOrPoison()` calls native Release once; any response other than Released stores `_poisoned=true` and forbids future mutation.

**PUBLIC `TryEnqueue(codec,payload)`** acquires one NoWait Mutex, rechecks poison, refuses Full or invalid canonical frame, and advances tail/depth only on complete Begin. On a failed unlock *after* enqueue it returns `QueuedButLockReleaseFailed` with FrameWasQueued=true; no rollback or queue-reset lie is permitted. **PUBLIC `PumpNext<TEndpoint>(endpoint)`** borrows an existing EDP-System ByteWriteEndpoint, takes that same ordinary Mutex, pumps only the current oldest accepted-byte suffix, advances head/depth only after Complete, and reports a truthful `FrameCompleted` even when the following Mutex Release failed. The status enums distinguish native Full/Busy/ProviderFailure/LockReleaseFailed/Poisoned; queue depth is never a remote durability ACK.

**PUBLIC `Depth()`** returns an atomic acquire-ordered occupancy snapshot; **`Poisoned()`** returns a sticky poison snapshot. Neither accessor locks nor proves the physical endpoint idle. Constructor borrows the real Mutex; copy/move are deleted because live frame and provider ownership must stay stable. Production endpoints require genuine Threading Mutex and exclusive physical native writer arbitration. The memory-only example fake Mutex proves single-context code shape, **not cross-task safety or UART delivery**.
