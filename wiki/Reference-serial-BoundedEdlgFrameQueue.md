# serial/BoundedEdlgFrameQueue.hpp — optional EDLG FIFO

**Public optional EDP-Serial adapter** on `feature/logging-v1`, version `0.1.0`. Does not enter the default Serial umbrella. Application imports `EDP-Serial`, **EDP-Logging** canonical EDLG framing and the **EDP-Threading** ordinary Mutex capability; all are abstractions, Bootstrap selects concrete platform Mutex and ByteStreamWriter providers. No deprecated `ESPressio-*` library.

- `EdlgQueueOfferStatus`: `Queued / Full / LockUnavailable / MutexProviderFailure / InvalidCodec / InvalidPayload / QueuedButLockReleaseFailed / Poisoned`.
- `EdlgQueueOfferResult`: `Status`, truthful `FrameWasQueued`, `DepthAfterAttempt`. An insertion followed by failed lock release retains the frame and poisons, NEVER lies that it was unqueued.
- `EdlgQueuePumpStatus`: `Empty / Complete / WouldBlock / ProviderFailure / EndpointContractViolation / LockUnavailable / MutexProviderFailure / LockReleaseFailed / Poisoned`.
- `EdlgQueuePumpResult`: `Status`, `FrameCompleted` (can be true even if lock release failed afterward), accepted prefix/total frame bytes and queue depth.
- `BoundedEdlgFrameQueue<FrameCapacity,MaxPayloadBytes,TMutexProvider>`: fixed array of owner-qualified `EdlgFramePump` elements; borrow a Bootstrap-composed EDP-Threading OrdinaryMutex provider whose `Identity`, CompositionOffers and typed noexcept TryAcquire/Release contract are compile-time enforced. `TryEnqueue(codec,payload)` reserves one FIFO slot by **single NoWait mutex acquisition**, formats/copies a whole frame, advances tail only on success and rejects Full/Busy. `PumpNext(endpoint)` holds same Mutex while pumping the oldest frame's **only unaccepted suffix** and removes it ONLY when all bytes were accepted. Nonblocking partial-native output cannot interleave with the next frame from this queue.
- `Depth() const noexcept` and `Poisoned() const noexcept`: lock-free atomic snapshots.

**Critical limits:** Exclusive endpoint ownership is a required Bootstrap contract. This queue only coordinates writers that participate in **this one queue**; another direct UART writer or independent queue can corrupt the stream. FIFO admission does not guarantee fairness to rejected producers. Never destroy with pending records; no stop/seal/worker/persistence/loss-provenance handling yet. An endpoint accepting bytes is NOT evidence of hardware flush, delivery or durability. A failed Mutex Release permanently poisons the queue; no unsafe Reset exists. Real Arduino/ESP-IDF ByteStreamWriter providers, complete physical target builds and HIL are outstanding.

**Tests:** `tests/BoundedEdlgFrameQueueTests.cpp` and `tests/run-bounded-edlg-queue-tests.sh`. Real composition offers with mock host providers, 8 competing producers × 12 repeats, partial output, verified complete CRC EDLG frames, full FIFO, native TryAcquire/Release failure, sticky poison.
