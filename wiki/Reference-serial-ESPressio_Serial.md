# src/ESPressio_Serial.hpp — PUBLIC default umbrella reference

This minimal maintained header is the user-facing C++20 discovery entry point and aggregation Type surface for **EDP-Serial**. It imports `<serial/ByteEndpoint.hpp>`, which itself imports `serial/SerialComposition.hpp`, so consumers may use the existing EDP-System Composition Domain/ByteStreamWriter and the standard byte-span `ByteWriteEndpoint`, `TryWriteComplete` and typed results without manually importing the internal source path. **No type, enum, alias, predefinition, constant or function is declared directly in this umbrella**: the only behavior is inclusion. Its compatibility guarantee is only these public abstract contracts, with no hardware, clock, heap, ISR, Threading, Logging, NVS or concrete provider created. Opt-in EDLG and FIFO headers must be included separately by their application-specific consumers, because importing the umbrella must never create a Logging→Serial dependency or Platform-specific dependency. See [source Byte Endpoint](Reference-serial-ByteEndpoint), [Composition](Reference-serial-SerialComposition) and [Dependency Contracts](Dependency-Contracts).
