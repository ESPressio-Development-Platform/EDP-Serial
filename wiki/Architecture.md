# Serial architecture (developer reference)

This repository owns *one* EDP-System Composition `Serial::Domain` and exclusive `ByteStreamWriter` capability, plus bounded progress/framing/queue adapters. **No second native platform provider** is constructed by this source. Default umbrella [ESPressio_Serial](Reference-serial-ESPressio_Serial) imports only the [Byte Endpoint](Reference-serial-ByteEndpoint); opt-in [Frame Pump](Reference-serial-EdlgFramePump) and [FIFO](Reference-serial-BoundedEdlgFrameQueue) import existing EDP-Logging framing and EDP-Threading Mutex respectively.

**Data path:** a caller supplies an already encoded borrowed byte span; `TryWriteComplete` attempts finite synchronous transfers, refuses WouldBlock without polling and reports exact prefix. Optional `EdlgFramePump` first copies one entire EDLG frame into a statically bounded member buffer, then retains the unaccepted suffix. Optional `BoundedEdlgFrameQueue` owns a fixed array of those pumps and a FIFO head/tail/depth under one borrowed Threading keyed Mutex. It acquires no native uart or Heap, and poisons after uncertain lock release.

**Not owned:** logger record creation, schema, Clock, native IRQ, UART port/pins, console routing, device drivers, delivery ACK, Flash persistence and application-owned thread shutdown. The concrete TX FIFO path lives in EDP-Serial-ESP-IDF, and its own Bootstrap must reserve the entire endpoint; a second out-of-band writer defeats frame atomicity even if this queue's Mutex works perfectly. Durable normative contract: [docs/ARCHITECTURE.MD](../docs/ARCHITECTURE.MD).
