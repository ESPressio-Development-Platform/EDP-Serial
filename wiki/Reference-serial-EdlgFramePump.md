# serial/EdlgFramePump.hpp — optional complete EDLG frame sink bridge

**PUBLIC opt-in adapter**, EDP-Serial `feature/logging-v1`, `0.1.0`. Conditional direct **EDP-Serial→EDP-Logging** dependency. Do not add reverse EDP-Logging→EDP-Serial or SDK-specific imports. No modification to the EDP-Serial default umbrella.

- `EdlgPumpBeginStatus : std::uint8_t`: `Queued=0`, `Busy=1`, `InvalidCodec=2`, `InvalidPayload=3`.
- `EdlgPumpStatus : std::uint8_t`: `NoFrame=0`, `Complete=1`, `WouldBlock=2`, `ProviderFailure=3`, `ProviderContractViolation=4`.
- `EdlgPumpResult`: strong Status, exact cumulative `AcceptedFrameBytes`, `TotalFrameBytes` plus `IsComplete() const noexcept`. Accepted does **not** equal flushed/received/durable.
- `EdlgFramePump<TMaximumPayloadBytes>`: noncopyable/nonmovable, owns fixed `std::array<std::byte,MaxPayload+20>`, size, offset and pending flag; no native Buffer/heap/Signal/global singleton.
- `Begin(Logging::EdlgCodec, span<const byte> encodedPayload) noexcept`: computes canonical Logging `WriteEdlgFrame` into PRIVATE owned buffer before exposing Queued; mutating the original payload after Begin cannot change the wire image. Reports Busy without replacing any partial frame, rejects codec/payload failures.
- `Pump<ByteWriteEndpoint>(ownerSelectedEndpoint) noexcept`: bounded finite `TryWriteComplete` of only the unaccepted suffix, records exact accepted prefix, retains the entire frame across WouldBlock/ProviderFailure/contract violation and releases frame slot only after Complete.
- `IsPending()`, `AcceptedFrameBytes()`, `TotalFrameBytes()`: state snapshots requiring caller-level exclusive owner coordination. No partially emitted frame Abort API.

**Critical preconditions:** the application must hold **exclusive access to the physical/USB/UART output endpoint across all Pump calls of the same pending frame**, not just around individual calls. Another pump or native UART printf can interleave bytes otherwise; this helper does not automatically serialize two producers. Underlying Serial provider must synchronously copy/accept bytes and not retain borrowed pointers. Never mistake BytesAccepted for delivered or durable; no concrete Arduino/ESP-IDF Serial provider exists yet. Physical target qualification and transport reset/loss-provenance path remain outstanding.

**Tests:** `tests/EdlgFramePumpTests.cpp` with `tests/run_logging_frame_host_tests.sh`, exact EDP-Logging 23-byte golden EDLG frame, mutation after Begin, partial/write-block/resume, failure, invalid/Busy and provider contract violation. ## Source-complete private frame state and method ownership — 12 November 2026

**Source:** [src/serial/EdlgFramePump.hpp](../src/serial/EdlgFramePump.hpp). The PUBLIC `EdlgFramePump<TMaximumPayloadBytes>` chooses exactly one fixed-size immutable-at-compilation maximum encoded source body. The complete EDLG output array has `TMaximumPayloadBytes + 20` bytes; the template's static assertions reject overflow of the 32-bit EDLG length and `size_t` capacity. The Type is noncopyable and nonmovable to avoid duplicating an in-flight native accepted prefix. A caller supplies an existing EDP-System Composition-qualified ByteWriteEndpoint; neither a native UART nor an asynchronous Task is created.

**PRIVATE `_buffer`** owns every complete EDLG frame byte across output retries; **`_size`** records exact valid whole-frame length; **`_accepted`** is the monotonic number of bytes a native provider already consumed; **`_pending`** identifies an exclusively live frame. The frame's source payload becomes independent of its caller immediately after `Begin` succeeds. The methods `IsPending()`, `AcceptedFrameBytes()` and `TotalFrameBytes()` report the live state without allocation and return zero counters when no frame is pending.

**PUBLIC `Begin(codec, encodedPayload)`** fails Busy before touching `_buffer`, and uses the canonical EDP-Logging frame encoder only on a new admitted payload. Exact typed statuses are Queued (0), Busy (1), InvalidCodec (2), InvalidPayload (3); an invalid attempt cannot overwrite a previously pending frame. **PUBLIC `Pump<TEndpoint>(endpoint)`** offers only the suffix `_buffer[_accepted.._size)`, adds the exact accepted prefix from EDP-Serial `TryWriteComplete` and clears `_pending`, `_accepted`, `_size` only after Complete. `EdlgPumpStatus` values NoFrame (0), Complete (1), WouldBlock (2), ProviderFailure (3), ProviderContractViolation (4) are distinct. `EdlgPumpResult` fields Status, AcceptedFrameBytes and TotalFrameBytes describe native acceptance, not wire receipt or filesystem durability; `IsComplete()` checks only Complete. The physical endpoint must remain reserved by the same application across *all* partial Pump attempts; another writer could otherwise interleave.
